========================================================
  贵州茅台 2024 年报 · 中文 RAG 智能问答系统
========================================================

【怎么启动】
  1. 双击 run_ui.bat
  2. 浏览器会自动打开 http://localhost:8501
  3. 页面首次打开还需等待约 60 秒（加载精排模型），属正常现象
  4. 黑色命令行窗口请【最小化】，不要关闭（关掉即停止服务）

  注意：如果双击后提示"服务已在运行"，说明已经有一个实例开着，
        浏览器会直接打开它，不会重复启动。

【文件说明】
  app.py            Streamlit 界面（聊天式问答 + 侧边栏调参）
  rag_engine.py     流水线引擎：切分 → 检索 → 精排 → 生成
  test.ipynb        完整实验与评测过程（Jupyter，含 RAGAS 四指标）
  requirements.txt  Python 依赖清单
  .env              两个 API Key（阿里云百炼 + DeepSeek）
  chroma_db_v2/     向量库（703 条子块，千问 text-embedding-v4，1024 维）
  store/            父子块缓存（删除后会自动重建，首次稍慢）
  贵州茅台2024年年度报告.pdf   数据源，143 页

【技术链路】
  PDF 解析 → 页眉正则清洗 → 父子块切分（父块 1500 字 / 子块 300 字重叠 50）
  → 千问向量化入库 → BM25(jieba) + 向量 混合召回 → bge-reranker-base 精排
  → 父块回填组装上下文 → DeepSeek 生成带页码引用的答案

【推荐演示问题】
  2024年营业收入是多少？
  茅台去年赚了多少钱？           （看"检索详情"里改写后的查询）
  每10股派发现金红利多少元？       （会主动区分三种分红口径）
  贵州茅台的核心竞争力是什么？
  董事长的手机号是多少？          （应明确拒答，不编数据）

【多轮记忆（可选）】
  侧边栏「多轮记忆」开关，默认关闭。
  · 关闭 = 单轮模式，每问独立检索、不携带历史（RAGAS 评测用的就是这一模式，保证可复现）
  · 开启 = 由 LangGraph checkpointer 保存历史，追问能承接上文

  开启后可以这样问（连问三句）：
    茅台去年赚了多少钱？
    那它的增长率呢？            ← 会把"它"解析成净利润，再去检索
    我上一个问题是什么？          ← 会如实回答上一句

  原理：checkpointer 只负责"历史存在哪"，真正起作用的是一个
  指代消解节点——先用历史把追问改写成独立问句，再拿去检索。
  否则检索器拿到的仍是"那它的增长率呢"这七个字，召回必然跑偏。

  注意：多轮模式下每轮多一次 LLM 调用（改写），且同一个问题在不同
  对话位置可能召回不同内容，因此做评测时必须关闭。

【注意】
  · 必须联网：向量化走阿里云百炼，生成走 DeepSeek，任一欠费都会报错
  · 报 Arrearage → 阿里云欠费；报 Insufficient Balance → DeepSeek 余额不足
  · 换电脑时：改 run_ui.bat 里的 PY 变量，指向装有 streamlit 的 python.exe
